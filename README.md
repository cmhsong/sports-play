# 🏆 모두의 스포츠 놀이

뇌성마비 학생 등 운동 조절이 어려운 학생도 스위치·터치·마우스로 즐길 수 있는 스포츠 게임입니다.

- 종목: ⚽ 축구 · 🏐 배구 · 🏸 배드민턴 · 🏓 탁구 (선수는 입체 음영을 넣은 8등신)
- 방향 익히기: "왼쪽으로 2번", "오른쪽으로 3번", "가운데로" 문제를 듣고 한 칸씩 이동 → 도착하면 슛! (문제 종류, 가장 많이 이동하는 횟수 1~5, 힌트, 틀린 방향 막기 설정 가능)
- 단계: 1단계 누르기 → 2단계 좌우로 움직이며 누르기 → 3단계 상대 공 받기 → 4단계 받고 빈 곳으로 공격 (5번 성공하면 자동으로 다음 단계, 끌 수 있음)
- 보조기기용: 스캔(스위치 1개), 직접 고르기(머무르면 선택 — 헤드마우스·시선)
- 조절: 동작 속도, 공이 날아오는 시간, 꾹 누르기 시간, 연속 입력 무시 간격, 스캔 속도, 화면 비율(자동·16:9·16:10·4:3·3:2·1:1)
- 버튼: 🏠 처음으로(길게 누르기 / Home 키), ⚙ 선생님 설정(길게 누르기 / F2)
- 이동: ← → 키, A/D 키, 화면 왼쪽·오른쪽 누르기, 게임패드 방향키 / 가운데로: ↑ ↓ 키, 스페이스, 화면 가운데 누르기
- 이동 방법 설정: 누르는 동안 계속 이동 · 한 번 누르면 한 칸 이동 · 마우스를 움직이면 선수가 따라가기
- 휴대폰·태블릿: 세로로 들어도 화면 비율이 고정되고, 놀이를 시작하면 전체 화면·가로 고정을 시도합니다(설정에서 끌 수 있음, 아이폰 Safari는 지원하지 않음)

주소로 바로 지정: `?sport=volley&mode=receive&ratio=4:3`
(sport: soccer, volley, badminton, tt / mode: simple, move, receive, rally, lr, scan, direct)

## 사용한 공개 소스

- [canvas-confetti](https://github.com/catdad/canvas-confetti) (ISC)
