# 🏆 모두의 스포츠 놀이

뇌성마비 학생 등 운동 조절이 어려운 학생도 스위치 하나·터치·마우스로 즐길 수 있는 스포츠 게임입니다.

- 종목: ⚽ 축구 · 🏐 배구 · 🏸 배드민턴 · 🏓 탁구
- 놀이 방법: 바로 하기 / 스캔(스위치 1개) / 직접 고르기(머무르면 선택 지원)
- 조절: 동작 속도, 꾹 누르기 시간, 연속 입력 무시 간격, 스캔 속도, 화면 비율(자동·16:9·16:10·4:3·3:2·1:1)
- 선생님 설정: 오른쪽 위 버튼 1초 길게 누르기 또는 F2

주소로 바로 지정: `?sport=volley&mode=scan&ratio=4:3` (sport: soccer, volley, badminton, tt / mode: simple, scan, direct)

## 사용한 공개 애니메이션
